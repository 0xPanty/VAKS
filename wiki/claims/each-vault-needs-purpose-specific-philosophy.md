# 主张：Each vault needs a purpose-specific philosophy

## 主张

每个 vault 应根据用途定义自己的组织哲学、质量标准和 AI 协作规则。工作 vault、研究 vault、创意 vault、开发资料库不应该强行套同一套模板。

## 为什么重要

用户的资料库同时服务开发项目、AI 短剧、优秀库设计采样、可信度治理。如果没有 purpose-specific rules，AI 很容易把内容工厂、知识库、项目决策和原始资料混在一起。

## 支持证据

- 一月文章明确主张 every vault needs its own philosophy。
- Yanhua 超级大脑文章强调 CLAUDE.md 编码身份、读者定位、写作偏好和 workflow。
- Claude Code 官方文档支持用 CLAUDE.md 管项目记忆和约定。

## 反例 / 冲突证据

- 过早写太多规则可能形成规则债。
- 长 CLAUDE.md 未必等于更好执行。
