# Frontier Principles

| Pattern | Borrowed product move | VAKS boundary |
|---|---|---|
| obsidian_bases_filtered_views | filtered table/card/list thinking for status surfaces | views display state only; filters are not approval |
| tana_supertag_typed_objects | typed objects with fields and collection views | typed cards do not create reviewed relations |
| capacities_object_first_capture | capture as objects instead of forcing folder choice first | capture creates raw/candidate orientation only |
| notebooklm_sources_chat_studio | three-panel movement between source, question, and generated artifact | generated output is not evidence support by default |
| notebooklm_goal_focused_chat | goal-scoped work modes for different user intents | goal mode cannot override validators |
| vaks_boundary_preserving_status | receipts, validators, status, and action boundary as visible product rails | status and receipts do not become authority |

These are design references only. They are not reviewed knowledge, not evidence
support, not action basis, and do not approve mainline changes.
