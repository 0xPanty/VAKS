## Revision Notes

Round 1 Boundary and Reviewer checks found two blocking gaps:

- feedback-event records incorrectly allowed `global_negative_knowledge: true`
  when `review_completed: true`;
- the validator only checked sandbox alias `effect_affects`, not canonical
  `affects`, and only blocked reviewed-note/relation mutations when encoded as
  booleans.

The current verification includes fixes for both:

- `global_negative_knowledge: true` is always blocked in feedback events;
- `affects` and `effect_affects` are checked together;
- non-empty text values in `reviewed_note_mutation`,
  `reviewed_relation_mutation`, or `reviewed_relation_strength` are blocked.
- dangerous authority flags are fail-closed, so text values in fields such as
  `mutates_reviewed_note`, `mutates_reviewed_relation`,
  `source_reliability_mutation_allowed`, `action_basis_allowed`,
  `global_negative_knowledge`, `creates_reviewed_relation`, and
  `promotes_reviewed_knowledge` are also blocked.
