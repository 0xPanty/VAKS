# Penguin AI-Ready Second Brain Candidate Distillation

## Boundary

This is a candidate distillation of a user-provided X article about making an
Obsidian second brain useful as AI context.

It does not modify mainline architecture, schemas, templates, or vault
structure.

## Plain-Language Takeaway

The useful part is:

```text
AI context needs more than saved information;
it needs the user's patterns, constraints, mistakes, decisions, taste, and
workflows;
notes become more useful when they record why they matter and where they can be
used.
```

For VAKS, this reinforces:

```text
activation uses context;
feedback and mistakes create review pressure;
prompts and workflows are visible files;
AI memory is not truth;
weekly loops should route candidates, not decide.
```

Candidate point:

```text
An AI-ready second brain should preserve repeated patterns, not only stored
notes.
```

VAKS fit:

```text
Supports activation and feedback surfaces.
```


### 2. full_context_notes_include_decisions_mistakes_prompts_workflows

```text
Decisions, mistakes, prompts, workflows, personal rules, and taste examples are
useful context categories for AI assistance.
```

VAKS fit:

```text

```

Boundary:


### 3. note_reason_fields_make_future_use_possible

Candidate point:

```text
A note becomes more reusable when it records why it matters, where it can be
used, what it connects to, and what question it raises.
```

VAKS fit:

```text
Supports source/candidate distillation and future context-pack usefulness.
```

Boundary:

```text
Reason fields improve usability, not evidence support.
```

### 4. taste_constraints_history_reduce_context_waste

Candidate point:

```text
AI chats waste context when the user repeatedly re-explains identity, goals,
style, constraints, and prior attempts.
```

VAKS fit:

```text
Supports handoff, CLAUDE.md / AGENTS.md style routing, and activation tier.
```

Boundary:

```text
Reducing context waste does not prove output correctness.
```

### 5. context_prompts_beat_random_prompts

Candidate point:

```text
Prompts that ask AI to inspect the vault for repeated ideas, contradictions,
next actions, and missing knowledge are more useful than isolated generic
prompts.
```

VAKS fit:

```text
Supports candidate review routing and context-pack preparation.
```

Boundary:

```text
The prompt output remains candidate-only.
```

### 6. repeated_patterns_are_activation_inputs

Candidate point:

```text
Repeated topics, ideas, mistakes, workflows, and unanswered questions can be
activation inputs for future work.
```

VAKS fit:

```text
Supports Activation Tier and operational-session-capture-loop.
```

Boundary:

```text
Repeated does not mean supported or true.
```

### 7. contradictions_and_mistakes_route_review_pressure

Candidate point:

```text
Contradictions and repeated mistakes should create review pressure rather than
```

VAKS fit:


Boundary:

```text
AI finding a contradiction is not resolution.
```

### 8. weekly_loop_turns_patterns_into_projects_decisions_prompts
