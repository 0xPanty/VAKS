The useful part of this source is not "use exactly these six folders."

```text
the hidden cost of research tools is connection cost;

capture adapters are pipes, not knowledge layers.
```

## Source Comprehension

### What The Article Is Really About

The article describes a move from five disconnected tools into one research
workbench:

```text
all captures land in Inbox
processed materials become Source notes
observations become Ideas
active threads live in Projects
finished work goes to Outputs
Claude-related instructions / skills / logs live in a separate support folder
```

Its main mechanism is connection cost reduction:

```text
same environment
same file surface
same source-processing template
same weekly synthesis prompt
same AI context window
```

The source emphasizes that capture consistency is the most fragile part. If
capture stops, weekly synthesis and connection-finding degrade quickly.

### What The Article Is Not

It is not:

```text
a controlled comparison of research tools
a validated cost-benefit study
a security review of Telegram / Zapier / Make / n8n
a verified Claude Projects setup guide
a VAKS architecture decision
a source of reviewed evidence for action basis
```

It is a useful practitioner workflow sample.
