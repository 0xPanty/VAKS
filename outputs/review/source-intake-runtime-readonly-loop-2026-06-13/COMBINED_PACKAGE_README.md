# Combined Review Package

This outer package contains two separate inner packages.

## 1. Full Pro Review Package

File:

```text
source-intake-runtime-readonly-loop-pro-review-package.zip
```

Use this for Pro reverse audit. It contains runtime summaries, cases, mapping,
scripts, reports, package manifests, and judge-packet hygiene evidence.

This package is not blind. Do not give it to a relevance judge before scoring.

## 2. Judge-Only Blind Relevance Package

File:

```text
external_blind_relevance_judge_only.zip
```

Use this for external / Pro blind relevance scoring. It intentionally excludes
internal mapping, runtime cases, expected outcomes, risk targets, and support
refs.

## Boundary

This combined package is still sandbox runtime evidence only.

It does not prove:

```text
Source Intake P0 passed
external blind relevance completed
live agent/tool loop validated
live retrieval/embedding exclusion validated
runtime adoption readiness
```
