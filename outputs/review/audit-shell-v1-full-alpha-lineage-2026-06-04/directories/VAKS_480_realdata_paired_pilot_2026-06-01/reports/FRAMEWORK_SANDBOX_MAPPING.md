# Framework Sandbox Mapping

Status: candidate-only mapping. This is not a main-vault writeback and not a `SCHEMA.md` change.

## Recommended Sandbox Shape

Use the smallest viable shell:

- hard-trigger shell
- required unresolved gate
- anchor health strip
- sparse provenance pointer

Treat recurrence as an optional bundle:

- representative exemplar recurrence card
- open-only dedup group
- versioned fingerprint grouping
- manual grouping guard
- serious breakout

Treat lint and wording as guardrails, not value engines:

- authority boundary lint
- categorical feedback strip

## Route Fit

| VAKS route surface | sandbox mechanism | boundary |
| --- | --- | --- |
| Capture / Provenance | sparse provenance pointer + anchor health strip | provenance is traceability, not support |
| Review / Consolidation | hard-trigger shell + full audit only on triggers | shell is review routing, not truth |
| Association / Reviewed Relations | no automatic relation creation | grouping is not reviewed relation |
| Activation / Dev Context | required unresolved gate | queue priority is not confidence |
| Context Pack / Decision | action-basis triggers deep packet | ordinary query stays light |
| Use Ledger / Feedback | categorical feedback strip | feedback changes usefulness/scope-fit, not truth |

## Sandbox Admission Conditions

Allowed into sandbox operation convention draft:

- unresolved-first default queue
- anchor health visible on front
- sparse source/record/evidence pointers
- full audit retained for action-basis, conflict, challenge, known omission, anchor problem, regression, action outcome
- optional recurrence card only for open ordinary valid-anchor items
- versioned fingerprint required whenever recurrence grouping is enabled

Not allowed into main truth core:

- line/char/review_proxy metrics as product proof
- authority lint as semantic safety proof
- grouping count as evidence strength
- source count or lineage as independence proof
- feedback numeric deltas
- dashboard/test/report pass as truth authority

## Current Readout

The strongest alpha is `shell_core`.

`shell_core_plus_recurrence` is a conditional positive alpha. It gives small global improvement in the 480 mixed pilot and clearer benefit under recurrence-heavy stress. It should not be treated as always-on core until real messy grouping extraction is tested.

Authority lint should remain CI/review lint. The paraphrase fuzz missed 7 of 16 samples, which is useful evidence that it cannot be promoted as a semantic firewall.
