candidates should move from sandbox into the VAKS main architecture.

main architecture docs, then used Misa as a second real project sample.

Main result:

```text
The mechanisms are useful in sandbox.
The object model is not mainline-ready.
Keep current mainline minimal.
```

Please review especially:

- whether the Misa second-project sample is strong enough;
- whether `candidate experience snapshot` and `candidate boundary snapshot`
  are sufficiently weak names;
- whether `default retrieval precedence` solves the authority leakage risk;
- whether any of the seven candidates deserve promotion beyond sandbox after
  this test.
