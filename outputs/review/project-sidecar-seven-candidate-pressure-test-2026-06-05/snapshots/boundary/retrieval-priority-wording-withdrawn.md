# Withdrawn: Retrieval Priority Wording

## Change Reason

The phrase `retrieval priority` is too easy to misread as importance,
confidence, support strength, or authority.

## Withdrawn Wording

```text
reviewed core > snapshots > active Lens > archived Lens > tombstone
```

This ordering is useful only as default inclusion/read order, but the word
`priority` makes the epistemic reading too tempting.

## Successor

Use:

```text
default retrieval precedence
default search inclusion order
default read order
```
