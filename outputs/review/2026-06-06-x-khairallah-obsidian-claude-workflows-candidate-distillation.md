# Khairallah Obsidian Claude Workflow Catalog Candidate Distillation

## Boundary

This is a candidate distillation of a user-provided X article listing Obsidian
plugins, Claude workflows, and advanced agent/vault setups.

It does not install, recommend, verify, or adopt any listed tool.

## Plain-Language Takeaway

The useful part is not the "30 things" list.

The useful part is:

```text
almost every AI vault workflow has the same safe shape:
read a bounded vault slice;
produce a candidate output;
save it visibly;
route review;
never confuse tool output with truth.
```

For VAKS, this is mainly a boundary-pressure catalog:

```text
RAG chat is activation.
Dataview / graph / tasks are workbench surfaces.
Ingestion creates candidates.
Vault health is lint.
MCP / CLI access needs permission tiers.
AI-generated notes need quarantine.
```
