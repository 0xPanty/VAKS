# Candidate Boundary: Misa Graph Carrier Is Not Controller

## Scope

This note records a Misa-specific boundary for graph or LangGraph-shaped carrier
layers.

## Boundary

Misa may use graph-shaped structures for context movement, but deterministic
control should stay outside graph rank, graph routes, or summaries.

## Applicability

Use this note only for projects where:

- Graph or route structures are used as carriers.
- A separate deterministic control contract exists.
- A graph route could be mistaken for control authority.

## Boundary Of This Boundary

This is not a general ban on graph-shaped systems. It only preserves the local
Misa split between carrier/context and control authority.
