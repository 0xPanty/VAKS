## MCP 服务器（reminds-mcp）

reminds 提供 MCP 服务器，可与支持 MCP 协议的 AI 客户端集成。

### 前置条件

获取 API 密钥：打开 reminds → 设置 → 安全 → 开发者 → API 密钥

### 支持的工具

- **create_fleeting**：创建闪念（HTML 格式）
- **get_fleeting**：获取闪念内容
- **search_notes**：语义搜索笔记（支持 qa 精确问答和 retrieval 广泛检索两种模式）
- **get_notes**：批量获取笔记内容

### 集成方式

#### 本地模式

适合有 Node.js 环境的用户，通过 npx 运行本地 MCP 服务器。
适用客户端：Cursor、Windsurf、Claude Code 等。

```json
{
  "mcpServers": {
    "reminds-mcp": {
      "command": "npx",
      "args": ["-y", "reminds-mcp"],
      "env": {
        "API_KEY": "<你的 API 密钥>"
      }
    }
  }
}
```

#### HTTP 模式一

适合无 Node.js 环境、客户端支持非 OAuth HTTP MCP 的用户，直接连接远程服务器。

```json
{
  "mcpServers": {
    "reminds-mcp": {
      "type": "http",
      "url": "https://api.reminds-app.com/api/v1/mcp",
      "headers": {
        "X-Api-Key": "<你的 API 密钥>"
      }
    }
  }
}
```

#### HTTP 模式二

适合需要 OAuth 认证的客户端（如 Claude Desktop），使用 Remote MCP Server URL。
在客户端中添加 Remote MCP Server，填入以下地址：

```
https://api.reminds-app.com/api/v1/mcp
```

客户端会自动完成 OAuth 认证流程，通过手机验证码登录后即可使用。
